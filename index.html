SDM Workshop

This workshop introduces Species Distribution Modelling using R and open datasets. Explore spatial data, species occurrences, environmental predictors, and learn to fit, assess, and compare species distribution models including GLMs, Random Forests, and MaxEnt. Build your skills to generate predictions and ensemble models confidently.

Konstans Wells

Biodiversity, Animal Health and Ecosystems (BAHE) Group, Swansea University

One workshop, two learning routes

This website is designed for students who are relatively new to R as well as those developing an postgraduate or other research project. You do not need to understand every R command before you begin. Start with the guided practical, copy and adapt the code in RStudio, and use the explanations, figures and interactive maps to link computing steps with ecological questions.

Core practical: work progressively through spatial data, species records, environmental predictors, background or pseudo-absence sampling, a first generalised linear model (GLM), model assessment and mapping. Progress at your own pace during the postgraduate PC lab. Start the core practical: Spatial Data in R →

Research extension: revisit the foundational decisions and explore BRTs, GAMs, Random Forests, MaxEnt, ensembles, spatial validation, transferability and uncertainty as your research questions require.

What will you learn?

By the end of the core practical, you should be able to:

  • Explain what SDMs can — and cannot — tell us about species distributions.
  • Explore spatial data and distinguish occurrences, verified absences, pseudo-absences and background samples.
  • Connect predictor choice, spatial scale and data quality with ecological hypotheses.
  • Fit and interpret a GLM using annotated R code.
  • Assess model performance and interpret a map of predicted environmental suitability, while recognising uncertainty.

For advanced research, the focus is on justifying choices about sampling bias, predictors, validation, model comparison and prediction under new conditions — not simply fitting more algorithms.

NoteBefore your practical

1. Download the workshop materials

Download the SDM Workshop student files (ZIP).

The download contains:

  • Prepared species occurrence and environmental datasets (data/)
  • Supporting R scripts and functions (scripts/)
  • Additional files needed for the practical exercises

Extract the ZIP file into a folder of your choice, for example SDM_Workshop.

Keep the supplied folder structure unchanged, as the exercises use relative file paths.

2. Create your own RStudio project

Open RStudio and select:

File → New Project → Existing Directory

Browse to the extracted SDM_Workshop folder and select Create Project.

RStudio will create a project file (.Rproj) and use this folder as your working directory.

Next, create a new R script:

File → New File → R Script

Save it as 01_SDM_practical.R in your project folder.

You can now copy R examples from this website into your script, execute them and add your own comments.

3. Check your setup

Run the short setup check below to confirm that R can find the supplied datasets and required starter packages.

Some additional packages may be needed for later chapters. These will be introduced where required.

4. Working with real ecological data

SDMs combine species observations with environmental predictors. Species records may come from field surveys, existing research collections or open databases such as GBIF. Environmental predictors may come from field measurements or repositories providing climate, elevation and land-cover data.

The workshop demonstrates how to obtain and prepare these data using R.

However, live data downloads are optional during the practical. Prepared datasets are supplied so that you can complete the exercises even when online data services are unavailable or slow.

You will still learn to explore, manipulate and analyse the data yourself. Downloading and preparing new data is an important extension for independent research.

If you get stuck

Check that you are working in the correct RStudio project and that the supplied files are available.

You can reload the appropriate prepared dataset and restart an exercise using the code displayed on the website.

Keep your own R scripts and comments so that you can return to your work and understand the steps you have completed.

For original data sources, download code, package information and reproducible preparation methods, see the optional Data Preparation reference chapter.

TipFirst step in RStudio: check your setup

Create your RStudio project as described above.

Copy the following code into your new R script and run it.

# 1. Check the project working directory
getwd()

# 2. Check introductory R packages
core_packages <- c(
  "terra", "sf", "geodata", "ggplot2",
  "dplyr", "rnaturalearth", "leaflet", "pROC"
)

missing_packages <- core_packages[
  !vapply(core_packages, requireNamespace,
          logical(1), quietly = TRUE)
]

# 3. Check the supplied workshop datasets
required_files <- c(
  "data/workshop_data.RData",
  "data/Clim_UK.tif",
  "data/Elev_UK.tif"
)

missing_files <- required_files[
  !file.exists(required_files)
]

# 4. Report results
if (length(missing_packages) == 0) {
  message("Starter packages: OK")
} else {
  message("Missing packages: ",
          paste(missing_packages, collapse = ", "))
}

if (length(missing_files) == 0) {
  message("Workshop data files: OK")
} else {
  message("Missing files: ",
          paste(missing_files, collapse = ", "))
}

If both checks report OK, the listed starter packages and files are available.

If any files are missing, check your project folder before changing the working directory.

This initial check does not test every package or dataset required by advanced exercises.

NoteInstalling missing R packages

If the setup check reports missing packages, run the following code in the same R session:

# Install packages identified by the setup check
if (length(missing_packages) > 0) {
  install.packages(
    missing_packages,
    repos = "https://cloud.r-project.org"
  )
}

Packages normally need to be installed only once in an R environment. However, they must be loaded using library() when needed in a new R session.

Each chapter introduces its required packages.

Advanced exercises may require additional packages, including mgcv, gbm, dismo, randomForest, maxnet, biomod2, sdm and ENMeval.

See Data Preparation for further package information.

How to use the code and interactive outputs

Read → run → inspect → change → explain.

The aim is not simply to reproduce the examples shown on the website, but to develop your own understanding of R coding and the ecological reasoning behind each step.

Build your own R script as you work through the tutorial:

  1. Read the ecological question and explanation.
  2. Copy and run the R code in your own script.
  3. Inspect the resulting figures, tables and maps.
  4. Change a predictor, model formula or plotting option and rerun the code.
  5. Explain the result in your own comments, including any ecological interpretation or limitations.

Add short comments to your script using # to explain what you are doing and why.

Beyond the core practical

After completing the introductory GLM workflow, the workshop provides further material for independent MRes, PhD and other research projects:

  • Fitting & Comparing Algorithms — GAMs, BRTs, Random Forests, MaxEnt and the assumptions behind model comparisons.
  • Ensemble Modelling — model combination, differences among predictions and uncertainty.
  • Assessment & Projection — spatial validation, transferability, extrapolation and environmental novelty.
  • Data Preparation — data sources, reproducible preparation and documentation for independent research.

For research, the aim is not simply to fit additional algorithms but to justify scientific decisions about sampling bias, accessible areas, predictors, evaluation, transferability and uncertainty. Useful references include the ODMAP reporting framework and Valavi et al. on spatially separated cross-validation.
